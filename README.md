# Pokeval

Poker evaluation library that supports 5 and 7 card hands, and includes a
"five-of-a-kind" rank (for engines that use wild cards).

There have not been any releases yet, but this library is maintained and used
by [Dealer's Choice](https://dealer-s-choice.github.io/).
